# Textlet

面向 macOS 14 Intel 的原生纯文本编辑器。Swift + AppKit，无 WebView、Electron、第三方运行时和语言服务器。当前版本为 **0.5.2**，默认采用已试用的 CPU/内存平衡绘制实现。50MB 不是所有场景下的硬上限，性能取舍见 [平衡报告](docs/逐行绘制CPU内存平衡-2026-09-28.md)。

## 运行

运行 `bash scripts/build.sh`，得到正式项目的 `build/Textlet.app`，可拖进“应用程序”目录。本机构建采用临时签名，尚未公证。安装前退出旧 Textlet，避免同一草稿目录被两个进程使用。

## 0.5.1 修复与优化

- 草稿恢复回退前归档原有清单和所有正文，保留较新及中断保存留下的可恢复内容；归档失败时保留原数据。

- 缓存最多 128 个行号标签的尺寸，减少重复测量；正文摘要使用固定缓冲区转换，保持编辑、撤销后的保存状态即时更新。

## 0.4 功能

- **经典 Monokai。** 固定深橄榄灰底色、暖白正文和琥珀色标签标记，统一正文、行号、标签和状态栏；使用原生控件及纯色绘制。
- **SQL / YAML / TOML 基础高亮。** 打开 `.sql`、`.yaml`、`.yml`、`.toml` 自动识别，扩展名不区分大小写。通过“语法”菜单手动切换，或选“纯文本”关闭高亮；每个标签独立保存选择，重启恢复。新建文本默认纯文本。“按文件名自动识别”模式下，重命名后会重新识别。
- **大文件保持纯文本。** 超过 8MiB 或手动以只读日志模式打开的文件均不高亮，保留分段查看和全文件搜索。

SQL 识别常用关键词、引号文本、数字和注释；YAML 识别常用键名、引号文本、布尔值、数字、注释和缩进块文本；TOML 识别配置段、键名、字符串（含三引号）、数字、布尔值和注释。这是基础着色，不是完整语法解析器，不提供语义分析、错误检查或代码补全；部分 SQL 方言及复杂配置语法可能不会准确着色。


- **标签滚动条。** 底部显示 3pt 浅灰色圆角细条，固定使用滚动时显示、停止后自动隐藏的样式，不受 macOS 常显滚动条设置影响。滚动和淡出仍由系统处理，无常驻计时器。

- **替换：`⌘R`。** 打开 macOS 原生查找替换栏，支持单次替换、全部替换、撤销和重做。只读日志不可替换；切到日志时关闭普通替换栏，日志仍使用全文件搜索。查找和替换输入框也关闭智能引号、破折号和自动纠错。
- **双击标签栏空白处新建文本。** 点击已有标签仍然切换标签；单击空白处不新建。
- **鼠标中键关闭标签。** 在标签上按下并松开滚轮，关闭鼠标指向的标签，无需先选中；移出标签后松开则取消。关闭时沿用原有保存提示。
- **正文标题。** 新建的普通文本标签随编辑显示第一条非空行，忽略首尾空白；内容为空或只有空白时恢复该标签原来的 `文本N`。长标题省略显示，悬停可查看较长的标题预览。原标题编号保留，不影响后续新建编号、语法识别和默认导出文件名。手动重命名后固定使用手动名称；打开的文件、只读日志及升级前已有标签继续显示原名称。自动标题和手动命名状态在重启后保留。
- **复用标签控件。** 切换标签只更新选择状态，避免反复销毁、创建按钮、约束和标签视图；正文和撤销记录不因此删除。进入后台时，在辅助线程归还分配器已经空闲的内存页，不清除仍在使用的正文和撤销记录。

## 编辑与查看

- **Finder 临时打开。** 右键“打开方式 → Textlet”或“打开方式 → 其它…”选择 Textlet.app，可打开 `.xml`、`.csv`、自定义扩展名、`Dockerfile`、`.env` 等纯文本。未知类型是否直接出现在一级菜单由 macOS 决定，可使用“其它…”选择。临时打开不会主动改变默认应用；应用内“文件关联”仍保留固定列表。
- **按内容检查。** 图片、压缩包、PDF 等可识别的二进制文件提示“此文件不是受支持的文本文件”，不新增标签。只检查开头最多 16KiB，因此可能漏识别后部才出现的二进制内容；普通文本仍执行原有完整无损解码。检测和资源测量见 [Finder 打开验证报告](docs/Finder临时打开验证-2026-10-10.md)。
- **JSON 格式化：`⌘⇧J`。** 有选区时格式化选区，否则格式化全文；两空格缩进，一次撤销即可还原。保留键顺序、重复键、数字原始表示和字符串转义；非法 JSON 提示错误，不修改原文。单次输入限 2MiB、输出限 8MiB、嵌套限 128 层，避免异常输入撑大内存。
- **行号。** 仅绘制可见逻辑行；自动折行不会增加行号。小文本支持 LF、CRLF、CR 和 Unicode 换行。大日志按 LF/CRLF/CR 计数，显示文件中的绝对行号。
- **大日志分段查看。** 超过 8MiB 的文件自动进入只读模式；小文件也可通过“文件 → 以只读日志模式打开”使用。每段约 48KiB，后台以 256KiB 缓冲扫描并建立稀疏行号索引，不把整个文件读进编辑器或复制到草稿。

## 大日志操作

顶部工具栏可跳到开头、末尾、上一段、下一段，也可拖动位置滑块跳转。索引建立期间先显示开头，索引完成后可任意跳转。段内使用普通滚轮滚动、选择和复制；**全选只选中当前段**。

`⌘F` 聚焦全文件搜索，回车或 `⌘G` 查找下一个，搜索至末尾会从开头继续。搜索为区分大小写的 UTF-8 字面搜索，不支持正则；单次查询最长 4096 字节。“停止”取消当前扫描。查找结果会定位并选中对应文本，搜索不会保存全文件匹配列表。

- 大日志支持 UTF-8 / ASCII。UTF-16/32 BOM 文件会提示先转换；无效 UTF-8 字节在视图中显示为 `�`，原文件不变。
- 超长单行也分段，续段第一行用 `↳` 标识，状态栏显示实际起始行号。
- 文件发生追加、截断、修改或替换后，点击“重新载入”读取新内容；当前不自动追踪实时日志。
- 退出后恢复路径、分段位置和段内滚动位置。原文件缺失时该标签显示错误，其他草稿仍能恢复。
- 日志只读，`⌘S`、`⌘R` 和 JSON 格式化不可用；关闭日志标签不删除原文件。

## 日常操作

| 快捷键 | 操作 |
| --- | --- |
| `⌘N` | 新建文本 |
| `⌘O` | 打开文本；超过 8MiB 自动进入只读日志模式 |
| `⌘S` | 保存到关联文件；新建草稿或原文件丢失时选择保存位置 |
| `⌘⇧S` | 另存为 UTF-8 文件，并关联到新路径 |
| `⌘⇧J` | 格式化选中 JSON 或全文 |
| `⌘F` / `⌘G` | 查找 / 查找下一个 |
| `⌘R` | 查找并替换（普通文本） |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做 |
| `⇧⌘]` / `⇧⌘[` | 下一个 / 上一个标签 |
| `⌘+` / `⌘-` | 放大 / 缩小文字 |
| `⌘W` | 关闭当前标签；未修改文件和空草稿直接关闭，需要保存时询问 |
| `⌘Q` | 保存会话并退出，下次恢复 |

关闭窗口也会保存会话并退出。要保留文本，直接退出即可，不必逐个关闭标签。

主动关闭有未保存修改的标签时提示“您想保存对文件所做的更改吗？”，按钮从左到右为“不保存、保存、取消”。关联文件保存成功后关闭；新建草稿或原文件丢失时打开保存面板，保留可修改的原文件名。取消或保存失败会保留标签。关联文件被清空也是未保存修改；空白新标签直接关闭，空格、换行算内容。新建标签依次命名为 `文本1`、`文本2`、`文本3`……，编号取当前已有“文本N”名称中的最大编号加一，不补中间空缺；打开文件的其他名称不占用编号。关闭最后一个标签后会保留一个新的空白 `文本1` 标签。已有标签名称（包括旧版默认名称和手动命名）原样恢复。

窗口退出时的尺寸与位置随会话保存，下次启动恢复；双击标题栏放大后的窗口同样恢复为放大尺寸。显示器断开或分辨率改变时会调整到当前屏幕可见区域。

普通文本打开后关联原文件，`⌘S` 直接保存回该文件，保留原编码、BOM 和原文换行。新草稿首次保存为 UTF-8，之后成为文件标签并显示文件名；“另存为”改用新路径，“导出副本”不改变关联。文件标签的重命名菜单禁用，可通过“另存为”改用其他名称。重复打开同一路径、同一种模式会切换到已有标签（包含符号链接路径）。同一文件可以同时拥有普通编辑标签和只读日志标签；选择只读模式不会替换或丢弃已有的未保存编辑。每个普通标签有独立撤销记录。

未关联文件或有未保存修改时，关闭按钮显示圆点；已保存显示 `×`；原文件移走或删除时显示红色圆点。文件事件和应用激活时刷新状态，无常驻轮询。原文件丢失后保存会打开保存面板，不自动重建原路径；外部修改在保存时提供取消、覆盖原文件和另存为。取消保存时，内容和关联保持不变。

退出应用或关闭整个窗口只备份编辑现场，不询问是否写回文件。下次恢复正文、关联路径和未保存状态，即使原文件已丢失也保留标签内容。只有备份失败才阻止退出。升级前已有普通标签没有来源路径，继续作为草稿，不根据名称猜测原文件。

编辑区粘贴纯文本，关闭智能引号、破折号、自动文本替换、自动纠错、补全和智能空格插入。去除的是字体、颜色等格式；原文已有的弯引号、不换行空格等字符不会被擅自替换。

## 草稿与恢复

默认目录为 `~/Library/Application Support/Textlet/`，可从“帮助 → 打开草稿目录”访问。输入暂停 0.8 秒后备份；切换标签、切到后台和退出时也备份。这些操作不写回关联文件，不消除未保存圆点。

- 内容先写入新的修订文件，再原子替换会话清单，保留当前和上一代快照。
- 当前快照损坏时尝试上一代并提示；两代都损坏时停止加载，不覆盖原稿。
- 同一草稿目录只允许一个写入进程；保存失败会阻止正常退出。
- 0.4 可读取 0.1 / 0.2 / 0.3 会话；写入仍使用 v2 清单，新增可选的标签语言字段。
- 窗口位置使用可选的 `windowFrame` 字段；旧会话没有此字段时使用默认窗口大小。
- 撤销记录不跨重启保留；突然断电或强制结束进程仍可能丢失最后尚未保存的输入。

## 内存设计与边界

所有标签共用一个 `NSTextView` / `NSLayoutManager`。不活动且无撤销记录的普通标签在进入后台时释放正文缓冲。大日志仅保留稀疏索引和文件描述符；活动视图最多显示约 48KiB，文件内容不进入草稿和撤销记录。行号使用自绘栏，限制绘制范围，不使用系统标尺的附加视觉效果。

文件修改状态用 64KiB 缓冲分块计算 SHA-256，避免为比较复制整篇正文；长度不同时直接标记未保存。备份复用已经编码的字节，同一批会话中的临时对象按标签释放。同目录文件共用目录监听器，文件监听仅在文件被替换时重新建立；无关目录变化不触发标签刷新。关闭状态的两个图标共用，状态未变时不重复设置控件。测量范围与结果见 [文件状态资源优化报告](docs/文件状态资源优化-2026-09-30.md)。

高亮共用当前编辑器，只对可见范围添加临时文字颜色，最多覆盖 64Ki 个 UTF-16 单元；切换标签时释放高亮状态，不给后台标签保留着色副本。为识别前文中的多行注释/字符串，按约 4096 个 UTF-16 单元记录稀疏状态，远距离跳转分批扫描；输入和滚动事件合并处理，无空闲轮询。高亮不进入草稿、导出文本和撤销记录。直接粘贴超过 8Mi 个 UTF-16 单元的草稿也停止着色。

Java、Python、Rust 和 JSON 尚无语法高亮；JSON 格式化仍然可用。大日志采用分段查看，不是全文件连续滚动编辑。无限标签、撤销历史、字体缓存、窗口尺寸和系统绘制都可能影响内存。

“帮助 → 性能信息”显示进程 `TASK_VM_INFO.phys_footprint`、本次运行物理占用峰值、RSS、窗口尺寸和像素倍率，单位 MiB。50MB（十进制）约为 47.68MiB。测量不包含 WindowServer 和输入法等独立进程，采样可能漏掉瞬时峰值。自动测试含中文和 emoji，但不等于真实中文输入法或长时间常驻测试。

## 项目结构

- `Sources/`：应用代码，主控制器为 `Textlet.swift`。
- `AppIcon.svg` / `AppIcon.icns`：图标矢量源文件与应用图标。
- `Tests/`：轻量功能测试源码，只编入临时测试构建。
- `scripts/`：正式构建、临时测试和生成物清理脚本。
- `docs/`、`Benchmarks/`：性能报告、历史测量及验收记录；其中的旧命令只作历史证据。
- `build/`：本机构建产物，已被 Git 忽略。
- `dist/`：按发布版本号命名的 ZIP 安装包和校验文件，已被 Git 忽略。
- `test-output/`：保留的历史检查输出，已被 Git 忽略。
- `archives/`：整合前的本地项目归档，已被 Git 忽略。

## 构建与验证

需要 Xcode / Command Line Tools，目标为 `x86_64-apple-macosx14.0`。

正式构建只编译 `Sources/`，不会把测试和基准代码打进 Textlet：

```sh
bash scripts/build.sh
./build/Textlet.app/Contents/MacOS/textlet --build-info
```

自动验证使用独立 Bundle ID，在 `/private/tmp/textlet-tests.*` 内临时构建。脚本退出时会注销并删除测试应用和临时目录：

```sh
bash scripts/test.sh
```

需要检查真实窗口、Finder 打开方式或系统菜单时，只构建一个 `build/Textlet.app` 手动检查；检查完成后清理本地应用包及其 Launch Services 注册：

```sh
bash scripts/clean-generated.sh
```

`scripts/build.sh` 仍可接收自定义 `.app` 输出路径。需要重新生成图标时，执行 `bash scripts/build-icon.sh`，随后重新构建。已退役的实验构建、Finder 自动探针和性能基准不再保留可执行入口；历史结果继续保存在 `docs/` 与 `Benchmarks/`，不会被日常开发重新运行。
