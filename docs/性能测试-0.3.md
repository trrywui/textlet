# Textlet 0.3 功能与内存记录

记录日期：2026-09-26。环境：macOS 14.8.9、Intel MacBookPro15,1、Retina 2×，Release 优化构建。内存使用 `TASK_VM_INFO.phys_footprint`，单位 MiB；50MB（十进制）约为 47.68MiB。

## 结论

新增 ⌘R 替换和双击标签栏空白处新建，保留独立撤销、JSON 格式化、大日志查看和草稿恢复。小窗口的本轮测试可低于 50MB，但大窗口仍明显超过 100MB，尚未实现所有场景下低于 50MB。

## 对原来运行实例的检查

检查的是用户已运行约一小时的 0.2 版，未修改真实草稿内容。物理占用为 101.0MiB，系统记录的本次运行峰值为 310.2MiB。三个草稿合计只有 8,581 字节，窗口约为 1680×968 points。

`leaks` 报告 0 leaks / 0 bytes；堆中 Note、NoteTab、NSConcreteTextStorage 各三个，没有发现大量遗留标签或正文对象。这个结果不能排除仍被引用的缓存滞留，也不能解释历史峰值发生时的具体操作。

`vmmap` 中 owned unmapped 脏页约 47.9MiB、已分配堆约 22.7MiB；另有 IOSurface 和系统图形缓存。虚拟地址区间不能相加当作物理占用。结合窗口放大后的重复测量，窗口绘制和系统缓存是内存增长的重要因素，正文体积不是主要来源。作为数量级参考，一个 1680×946 points、2×、RGBA 的完整像素缓冲约占 24MiB；实际缓冲数量未测定。

诊断汇总：[live-0.2-summary.json](../Benchmarks/v0.3/live-0.2-summary.json)。

## 本次调整

- 复用标签视图，避免切换时反复创建按钮、约束和标签。
- 进入后台后，在辅助线程请求分配器归还已经空闲的页，不删除仍在使用的正文和撤销记录。
- 更新原生查找器的文本变更通知，确保跨标签替换使用当前正文；查找替换输入框也关闭智能引号、破折号和自动纠错。
- 修正查找栏打开后的行号绘制范围和滚动位置恢复。

没有用清空撤销记录或限制现有功能换取内存下降。不同运行的焦点、缓存和绘制状态存在差异，本报告不据此声称固定的优化百分比。

## 已完成的测量

三标签交互测试使用合成文本，执行 467 轮切换、编辑、撤销及临时标签创建关闭，约 90 秒。默认窗口为 860×590，放大阶段为 1680×946 points。

| 场景 | 采样峰值 MiB | 阶段结束 MiB |
| --- | ---: | ---: |
| 小窗口，打开并操作替换栏 | 45.38 | 38.19 |
| 小窗口，循环编辑和切换 | 40.68 | 39.52 |
| 大窗口，循环编辑和切换 | 179.94 | 179.76 |
| 大窗口，切到后台但仍可见 | 176.30 | 128.43 |
| 恢复小窗口后，后台空闲 | 32.16 | 31.03 |

系统记录的整次运行峰值为 **224.41MiB**，高于定时采样捕获的峰值。不能以采样峰值代替系统峰值。

另外两组已完成的回归均使用默认小窗口：

| 场景 | 系统峰值 MiB | 后台结束 MiB | 响应时间 |
| --- | ---: | ---: | --- |
| 500MB 日志与三个普通标签 | 46.52 | 29.50 | 建索引 1.67 秒，全文件搜索 2.23 秒 |
| 十标签，每个 1200 行 | 36.39 | 29.14 | 编辑 P95 5.41ms，切换最慢 31.54ms |

日志测试的后台阶段隐藏了窗口，与上表“后台但可见”不是同一条件。大日志采用约 48KiB 分段视图，不把 500MB 文件完整载入正文。

## 验证与限制

替换、全部替换、跨标签替换、撤销重做、字面字符保留、⌘R、空白处双击、已有标签与加号点击、标签栏滚动均通过。关闭临时标签后，Note、NSTextStorage 和 NoteTab 的弱引用均释放。日志只读保护、JSON 格式化、行号、会话持久化及重启恢复通过。

最终发布构建另做约 17 秒快速交互测试（12 轮）和重启恢复，全部通过。按用户要求不再追加长时间测试。测试使用隔离草稿目录，没有覆盖用户草稿或终止原来的应用。

这些是短时、本机、合成文本结果，不代表长时间常驻或真实中文输入法测试；不计入 WindowServer 和输入法等独立进程。原始结果保存在 [Benchmarks/v0.3](../Benchmarks/v0.3/)，其中 `interaction.json` 为完整交互记录，`release-ui.json` 为发布构建快速检查；窗口截图仅含合成文本。
