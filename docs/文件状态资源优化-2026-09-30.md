# 文件状态资源优化 · 2026-09-30

本次优化文件关联、未保存状态和标签图标的资源开销。保留保存/另存为、外部修改冲突提示、文件丢失红点、撤销还原状态、退出备份和重启恢复行为。

## 实现

- 文本指纹从整篇转换成 Swift String 和 UTF-8 Data，改为直接读取 NSString，用 64KiB 缓冲计算同样的 SHA-256。长度不同仍直接判定已修改；等长时完整校验，保留手动改回内容及撤销后的准确状态。
- UTF-8 无 BOM 的文件直接复用磁盘字节摘要。写文件时无 BOM 不再额外拼接一份 Data。会话备份复用已编码字节做比较，读取和备份多个标签时逐个释放临时对象。
- 圆点与关闭符号各共用一份图标；标签名称、路径和状态未变时跳过图标、颜色、提示文字和无障碍标签的重复设置。圆点 6pt、关闭符号 8pt、点击区域 18×18pt 保持原样。
- 同目录标签共享目录事件源，每个现存文件保留自己的事件源。文件身份未变时复用监听；无关目录变化不刷新标签。缺失文件监听最近仍存在的上级目录，目录替换、文件重新出现后重新绑定。最后一个订阅者释放时关闭目录事件源，无轮询计时器。

## 定向测量

同一台机器、相同 Release 编译参数与测量代码，每项优化前后交替运行三组，以下为中位数。CPU 为进程 user + system 时间；内存为进程 `TASK_VM_INFO.phys_footprint`，不包含 WindowServer。每轮独立进程，避免上轮分配器高水位污染结果。

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 480 万 UTF-16 单元文本，80 次等长修改及还原检查：CPU | 3.144 秒 | 2.082 秒 |
| 上述进程物理内存峰值 | 32.87 MiB | 22.45 MiB |
| 上述检查结束后物理内存 | 22.40 MiB | 22.45 MiB |
| 状态不变时重复更新标签 10,000 次：CPU | 0.992 秒 | 0.0085 秒 |

大文本场景节省约 10.43 MiB 峰值内存，CPU 减少约 33.8%。这主要消除了临时全文副本，结束后的常驻占用基本相同。标签微基准说明重复设置被跳过，不代表整个编辑器 CPU 降低同样比例。

普通现存文件的事件源数量从每标签两个，变为“文件数 + 不同父目录数”。例如同目录 40 个文件，从 80 个降到 41 个。移动和重建目录期间会有取消旧事件源的短暂过渡。

## 功能和整机窗口检查

- 155 项自测通过，包括分块边界的中文、emoji、组合字符、NUL、换行、非法 UTF-16 兼容，以及文件编码和权限保存。
- 新增共享监听、无关文件过滤、原子替换后继续监听、目录移走、重建、立即替换、订阅者迁移和最终释放检查，均通过。
- 70 项 GUI 交互检查通过，覆盖保存、取消、关闭、撤销、文件缺失、外部修改、标题和中键关闭。保存面板路径选择使用测试替身。
- 真实退出并重启后，已保存、已修改、缺失未修改、缺失已修改、未保存草稿五种状态及正文均恢复；退出未改写源文件。
- 截图检查确认小圆点和关闭符号外观保持一致。
- 完整应用在 1680×940pt、2× 显示下完成 160 次键盘输入和 160 次滚动，8 项检查通过。输入后空闲 CPU 为单核 0.188%，滚动后为 0.215%；该密集文本大窗口场景峰值约 96.1 MiB。优化前一次运行未始终保持前台，因此不把两次窗口数据作为严格性能增减结论。

这些优化没有调整既有行图片缓存预算；总占用仍受窗口尺寸、可见内容和撤销历史影响，不承诺所有场景低于 50MB。正文备份和显式保存仍需编码输出字节，等长内容的完整摘要仍随正文长度增长。

## 复现与结果

结果目录：`test-output/file-efficiency-20260929/`（沿用开始任务时的目录名，最终重复测量于 2026-09-30 完成）。`summary.json` 汇总三组数据，`hash-*-1/2/3.json`、`tabs-*-1/2/3.json` 为原始定向结果，`lifecycle.json`、`self-test-final.txt`、`restart.expected.restore.json` 和 `usage-after.json` 为功能及完整应用结果。构建对照保留于该目录的 `Before.app`。

```sh
bash scripts/build.sh
./build/Textlet.app/Contents/MacOS/textlet --self-test
./build/Textlet.app/Contents/MacOS/textlet \
  --file-efficiency-benchmark test-output/hash.json --efficiency-mode hash
./build/Textlet.app/Contents/MacOS/textlet \
  --file-efficiency-benchmark test-output/tabs.json --efficiency-mode tabs
```

标签测量需要可访问 macOS 图形会话；报告目录须事先创建。完整应用、文件会话及交互检查继续使用 README 中的独立目录流程。
