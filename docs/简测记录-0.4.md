# Textlet 0.4 简测记录

2026-09-26，macOS 14 Intel，Release 构建。

本次加入经典 Monokai 外观和 SQL / YAML / TOML 基础高亮。超过 8MiB 的文件及手动打开的只读日志保持纯文本。高亮共用现有编辑器，仅在可见范围添加临时颜色，不修改草稿内容或撤销记录；语言选择单独保存在会话中。

按用户要求，仅做针对性检查，没有重新执行大文件、长时间循环或全部历史测试。

- `--syntax-test`：7 项通过，覆盖三种语言、多行文本、Unicode 稀疏状态恢复、旧会话兼容、手动语言保存和只读文件禁用高亮。
- `--appearance-check`：约 8 秒，11 项通过，覆盖实际窗口着色、撤销后正文一致、切换标签重新着色、关闭高亮、语言选择保存、只读文件规则和原生替换栏。
- 实际窗口截图确认 SQL、YAML、TOML 配色及行号显示。检查期间发现切换标签后行号可能未及时重画，已在高亮完成后刷新行号，并在最终构建复查。

窗口为 860×590 points，Retina 2×，使用合成的小文件，包含临时笔记、三种语言标签和一个只读文件。结束时原生替换栏可见。最终构建的 `phys_footprint` 为 **39.73MiB**，系统记录的本次运行峰值也是 **39.73MiB**；RSS 为 60.02MiB，与物理占用口径不同。

这不是长期常驻测试，也没有测量“开启高亮前后”的严格对照，因此不能据此声称高亮固定增加多少内存或所有场景都低于 50MB。大窗口的历史占用边界仍见 [0.3 报告](性能测试-0.3.md)。

基础词法着色不等于完整语法解析；例如 PostgreSQL 美元引号、复杂 YAML 键/标签及部分 TOML 边界语法尚未完整覆盖。不会改变原始字符、格式化文件或运行 SQL。
