# 手动排序与正文切换分离，优先控制资源开销

手动排序只改变标签顺序，拖动未选中的标签时保留当前标签及正文，避免为了排序触发正文加载、排版和标签切换备份；普通点击在松手且未形成拖动时切换标签，因此接受从按下切换改为松手切换的交互变化。

拖动期间保持原排列，只显示插入位置线，松手后一次提交顺序，减少持续布局和动画开销；标签栏边缘自动滚动仅在拖动且靠近边缘时运行，离开边缘、取消或结束拖动后立即停止。

有效松手且顺序变化后执行一次现有会话保存，接受此时可能顺带备份待备份正文的开销，以沿用正文修订与会话清单的原子提交机制；失败时恢复原顺序并提示，移回原位置不触发排序保存。窗口失去焦点、应用进入后台或标签集合变化时取消本次排序，保留已发生的标签增删及当前标签栏滚动位置。

完整需求与验收场景见 [GitHub Issue #2](https://github.com/trrywui/textlet/issues/2)。
