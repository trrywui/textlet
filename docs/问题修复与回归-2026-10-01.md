# 问题修复与回归（2026-10-01）

## 修复内容

1. 普通编辑和只读日志按“规范化路径 + 模式”分别复用标签。同一个文件可以同时保留两种模式；只读打开不会覆盖已有未保存编辑。日志重复打开、符号链接以及旧会话中的未规范化日志路径均参与去重。
2. UTF-8 分段只在边界切入完整合法字符时向前对齐，最多移动 3 字节。无效字节保留在解码范围内并显示为 `�`，长串无效续字节不再产生无法前进的空页。截断的无效字符跨页时，替换字符的数量可能与整段解码不同，原始字节范围仍完整覆盖。
3. 标签切换失败统一抛出错误。打开过程在切换失败时撤回新增标签；已完成切换但最终备份失败时保留可见标签，并单独提示备份失败。普通文件和日志使用同一处理流程。
4. 日志模式补齐 UTF-32 大端 BOM 检查，同时保留 UTF-16、UTF-32 小端检查。
5. 文件关联失败后保留用户勾选；刷新系统实际状态不覆盖待处理选择。重试仅处理仍被勾选且未生效的失败项，主动取消勾选的项目不再重试。

原有前后台恢复、新建标签修复及交互测试改动保留。`selectNote` 的失败通知由布尔返回值改为抛出错误，调用方通过现有或新增的错误处理接收失败。
