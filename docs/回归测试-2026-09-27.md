# 关闭标签、窗口恢复与稳定性回归

2026-09-27，macOS 14.8.9，Intel x86_64，Release 构建。测试使用独立的 `/tmp/textlet-regression.*` 会话和合成文本，没有操作用户正常草稿。

## 本次修改

- 空普通草稿直接关闭；输入后清空、尚未加载正文的空草稿也适用。空格、制表符和换行仍算内容。
- 有内容时提示“您想保存对文件所做的更改吗？”。按钮从左到右为“不保存、保存、取消”，使用原生按钮；前两项为普通灰色，取消保留默认强调色及 Return / Escape 取消行为。macOS 14 的三按钮 `NSAlert` 会纵向排列，因此此处采用原生 `NSPanel` 固定横向布局。
- 保存继续使用 UTF-8 导出流程；成功后关闭，取消路径选择或写入失败则保留标签。关闭后台标签时导出该标签自己的正文。
- 关闭失败时恢复原标签列表和当前标签，修复原流程中“下一个草稿读取失败后当前标签失效”的问题。
- 在会话清单的可选 `windowFrame` 字段中保存窗口尺寸与位置；启动时恢复。旧会话使用默认尺寸，屏幕变化时约束到可见区域。

窗口实测：小窗口外框为 860×618 points，系统 zoom 后为 1680×968 points；退出后重新启动的尺寸和位置一致。本次没有覆盖独立 Space 中的原生全屏恢复。

## 内存和崩溃检查

功能回归运行中未观察到应用崩溃。最初在受限执行环境中直接启动 GUI 进程被中止，后续窗口测试在可访问 WindowServer 的环境运行；自动操作系统保存面板失败的尝试也没有计为通过。

- **`leaks` 压力进程扫描：0 leaks / 0 bytes。** 扫描时已经运行约 71 秒，经历编辑、撤销、关闭和大小窗口切换。
- **基础测试退出扫描：0 leaks / 0 bytes。**
- **带截图的关闭测试退出扫描：3 个块，共 272 字节。** 分配栈位于系统 `CoreImage` 的 `CI::ObjectCache<CI::MainProgram>::clear` / `CI::Object::performDeferredRoot`，涉及 dispatch queue / group；没有 Textlet 分配栈。不能将这份结果描述为“所有扫描均为零泄漏”。
- **关闭截图后的同流程复测仍为 272 字节。** 另外编译了一个不包含 Textlet 代码、仅显示原生 `NSAlert` 后退出的最小程序，扫描也报告了同一路径的 176 字节（dispatch queue 及其 specific 存储）。因此不能把残留简单归因于截图；基线支持它与系统弹窗/图像缓存路径有关，但没有证明所有应用级泄漏都不存在。本次没有修改系统框架或屏蔽扫描结果。
- **AddressSanitizer：** 基础 88 项、语法 7 项、关闭/保存/异常回滚 18 项全部通过，没有检测到越界或释放后访问。该轮关闭检查先于额外加入的两个键盘检查；应用生产代码相同。设置了 `detect_leaks=0`，泄漏检查由 macOS `leaks` 独立完成。

以下为未启用 AddressSanitizer 的 `TASK_VM_INFO.phys_footprint`，单位 MiB；峰值使用系统记录，可能高于定时采样捕获的最高值。采样不包含 WindowServer、输入法和其他进程，截图在大部分基准的采样结束后执行。交互测试期间进行了 `leaks` 扫描，因此这些数据不是严格隔离的性能对照实验。

| 场景 | 最后采样 | 系统记录峰值 |
| --- | ---: | ---: |
| 普通三标签编辑 | 32.63 | 79.18 |
| 十标签压力 | 42.04 | 87.77 |
| 467 次交互循环与大小窗口切换 | 33.95 | 210.80 |
| 100MB 日志 | 34.59 | 73.70 |
| 500MB 日志 | 34.42 | 64.02 |

交互测试的大窗口阶段稳定占用约 120MiB；缩回小窗口后约 65MiB，后台空闲后降至约 34MiB。这说明本轮没有持续累积的迹象，但**并非所有场景都低于 50MB**。短时回归与采样不能证明长期运行绝无泄漏；未覆盖多天常驻、真实中文输入法或物理显示器热插拔。
